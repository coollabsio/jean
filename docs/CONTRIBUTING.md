# Contributing to Jean

Jean's canonical contributor guide is the repository-level
[CONTRIBUTING.md](../CONTRIBUTING.md). It covers prerequisites, local setup,
development commands, project conventions, testing, and pull request
preparation.

Before changing code, also review the documentation for the area you are
working in:

- [Architecture guide](developer/architecture-guide.md)
- [Command system](developer/command-system.md)
- [State management](developer/state-management.md)
- [Testing guide](developer/testing.md)

Repository tasks and their completion workflow are described in
[Task Management](tasks.md).
