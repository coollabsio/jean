# Getting Started with Jean Development

Jean is a Tauri desktop application for managing projects, Git worktrees,
terminals, and AI coding sessions. This repository contains the Jean
application and its supporting documentation.

## Set up the repository

Follow the root [contributor guide](../CONTRIBUTING.md) for the current
prerequisites, platform dependencies, clone instructions, development command,
and quality checks. That guide is the source of truth for local setup.

## Understand the codebase

Start with these guides before making changes:

1. [Architecture guide](developer/architecture-guide.md) for the high-level
   frontend and Tauri backend design.
2. [State management](developer/state-management.md) for choosing between
   component state, Zustand, and TanStack Query.
3. [Command system](developer/command-system.md) for user actions and command
   registration.
4. [Testing guide](developer/testing.md) for test strategy and patterns.

Additional subsystem documentation is listed in the
[documentation index](README.md).
