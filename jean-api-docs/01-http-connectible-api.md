# HTTP Connectible API

Jean Web Access exposes a small HTTP surface plus a WebSocket endpoint.

## Server behavior

Routes configured in `src-tauri/src/http_server/server.rs`:
- `GET /api/auth`
- `GET /api/init`
- `GET /ws` (WebSocket upgrade)
- Static frontend fallback to `dist/index.html`

CORS:
- Open (`Any` origin/method/header).

Bind mode:
- `localhost_only = true`: binds `127.0.0.1:<port>`
- `localhost_only = false`: binds `0.0.0.0:<port>`

Defaults from preferences:
- `http_server_port = 3456`
- `http_server_localhost_only = true`
- `http_server_token_required = true`
- `http_server_auto_start = false`

## Auth model

Auth is query-param based when token auth is enabled.

Token generation:
- 32 random bytes
- Base64URL no-pad encoded
- Generated by `src-tauri/src/http_server/auth.rs`

Validation:
- Constant-time compare when lengths match.

## `GET /api/auth?token=...`

Use this before attempting WebSocket connection.

When `token_required = true`:
- Valid token -> `200` + `{ "ok": true }`
- Invalid/missing token -> `401` + `{ "ok": false, "error": "Invalid token" }`

When `token_required = false`:
- Always `200` + `{ "ok": true, "token_required": false }`

## `GET /api/init?token=...`

Bootstrap endpoint for web clients.

Returns a merged object with:
- `projects`
- `worktreesByProject`
- `sessionsByWorktree`
- `activeSessions` (only when active sessions exist in UI state)
- `preferences`
- `uiState`

Behavior details:
- Performs multiple backend calls in parallel.
- Partial failures do not fail whole response.
- `preferences` / `uiState` may be `null` on load failure.
- Session payload includes full active session message histories.

## `GET /ws?token=...`

WebSocket upgrade endpoint.

When token is required:
- Invalid/missing token -> `401` with `Invalid token`

On success:
- Client enters JSON text-frame RPC protocol (see `02-websocket-rpc-protocol.md`).

## Headless mode notes

In headless mode startup (`src-tauri/src/lib.rs`):
- Server is auto-started.
- URL/token are printed to stdout for easy automation.
- Bind behavior can be overridden for all interfaces.
